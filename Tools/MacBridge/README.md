# JARVIS Mac 읽기 서비스 · 개발 공간 1차

> 현재 기능 보류 상태입니다. iOS 화면·저장소는 `#if false`로 제외했고 아래 CLI의
> `main()` 호출도 주석 처리되어 인증서 생성·서버 시작을 하지 않습니다.
> 기존 실행 중인 서버는 해당 터미널에서 Control-C로 종료하세요.
> 연결 정보·인증서는 삭제하지 않았습니다. 아래는 재활성화 후 사용할 보관 안내입니다.

아이폰 **JARVIS → 왼쪽 위 개발 공간**에서 Mac 프로젝트 한 폴더를 탐색·읽기·텍스트 검색합니다.
REA나 외부 모델 없이 동작하며 코드를 채팅·장기 기억·클라우드 AI로 자동 전송하지 않습니다.
현재는 파일 뷰어/검색기입니다. 코드 설명·생성·수정·빌드·실행·Mac 채팅 앱은 아직 없습니다.

## 준비

- macOS, Python 3.10 이상(SSL 포함), `/usr/bin/openssl`
- Mac과 아이폰이 같은 신뢰할 수 있는 로컬 네트워크에 연결
- 시스템 설정 → 네트워크에서 Mac IPv4 확인. 아래 `192.168.1.20`을 **실제 주소**로 변경
- 관리자 권한·전체 디스크 접근·라우터 포트 포워딩·공개 터널은 사용하지 마세요.
- 비밀정보가 없는 전용 프로젝트부터 시작하세요. 민감정보 필터는 완전한 탐지기가 아닙니다.

아래 명령은 저장소 폴더에서 사용자가 직접 실행합니다. 자동 설치·상주 실행·네트워크 공개는 하지 않습니다.

### 1. 처음 한 번 TLS 인증서 생성

```sh
python3 Tools/MacBridge/jarvis_mac_bridge.py init --state "$HOME/.jarvis-mac-reader" --host 192.168.1.20
```

인증서/개인키는 소유자 전용 디렉터리에 생성하며 기존 인증서를 덮어쓰지 않습니다.
유효기간은 365일입니다. IP/인증서 변경 시 새 상태 디렉터리로 init하고 재등록하세요.

### 2. 허용 프로젝트 한 폴더로 서비스 시작

```sh
python3 Tools/MacBridge/jarvis_mac_bridge.py serve --state "$HOME/.jarvis-mac-reader" --host 192.168.1.20 --root "/absolute/path/to/your/project"
```

`--root`는 실제 프로젝트 절대 경로로 바꿉니다. 홈·Desktop 전체·Documents 전체·`/`는 거부합니다.
상태 디렉터리는 공유 프로젝트 밖에 두어야 합니다. 로컬 IPv4의 8765 포트에서만 수신하며 `0.0.0.0`·공인 IP·호스트명은 거부합니다.
방화벽이 묻는다면 Python 서비스의 로컬 연결 범위를 사용자가 확인하세요.

### 3. 아이폰 연결

1. Mac에서 `$HOME/.jarvis-mac-reader/pairing.json`을 본인만 볼 수 있는 편집기로 엽니다.
2. 전체 내용을 본인 아이폰에 안전하게 전달해 개발 공간 입력란에 붙여 넣습니다.
   **연결 토큰이 있으므로 채팅·이슈·공개 저장소에 올리지 마세요.**
3. 확인창의 주소·프로젝트·인증서 SHA-256을 Mac 파일과 비교하고 저장합니다.
4. **프로젝트 불러오기**를 눌러 실제 연결을 확인합니다. iOS 로컬 네트워크 권한이 필요합니다.
5. 폴더/파일을 누르거나 현재 폴더에서 검색합니다.

연결 정보는 `WhenUnlockedThisDeviceOnly` Keychain에 저장합니다. 앱 시작 시 자동 조회하지 않습니다.
화면 이탈·앱 비활성화·취소·긴급 잠금 때 조회와 화면 내용을 폐기하고 늦은 결과도 표시하지 않습니다.

### 4. 중지와 권한 회수

- 아이폰: **조회 중지·화면 내용 지우기**, **연결 정보 삭제**
- Mac: 터미널에서 **Control-C**
- 재시작마다 토큰과 프로젝트 ID가 바뀝니다. 새 pairing.json으로 다시 등록해야 합니다.
- 아이폰 연결 삭제는 해당 기기만 해제합니다. 복사된 토큰도 폐기하려면 Mac 서비스를 중지하세요.
- 아이폰의 긴급 잠금은 해당 아이폰의 조회를 막습니다. Mac 서비스 전체나 다른 토큰 소지자까지 차단하려면 Mac에서 서비스를 중지하세요.

## 보안 경계·제한

- HTTPS + 인증서 핀 + 호스트·유효기간 검증. HTTP 대체·리다이렉트는 거부합니다.
- API는 list/read/search뿐이며 파일 변경·임의 명령·프로그램 실행 API는 없습니다.
- 접근 로그에 요청·경로·본문·토큰을 기록하지 않습니다.
- 루트 디렉터리 FD 기준 조회. 경로 탈출·심볼릭 링크·하드 링크·장치·다른 파일시스템 접근 차단.
- 숨김/빌드/의존성/일부 민감 이름·내용은 제외합니다. **모든 비밀정보 탐지를 보장하지 않습니다.**
- UTF-8 텍스트 64 KiB 이하, 내용 해시 확인, 리터럴 검색만 지원합니다.
- 폴더 80항목, 검색 40결과/1,000항목/8단계/약 2초 제한. 일부 결과면 화면에 표시합니다.
- 읽기 중 크기·수정 시각 변경 시 거절합니다. 프로젝트 전체의 원자적 스냅샷은 아닙니다.
- Mac 잠자기·서비스 종료·IP 변경·네트워크 단절 시 사용 불가. 인터넷 원격 연결·자동 발견·iCloud 미지원.
- API 제한은 Mac OS 전체 샌드박스가 아니며 같은 OS 사용자의 악성 프로세스에 대한 격리는 보장하지 않습니다.
- 첫 버전은 토큰 소지자 인증입니다. 기기별 토큰 관리 UI·자동 토큰 만료는 미지원이며 서비스 종료/재시작으로 회수합니다.

## 검증

```sh
python3 -m unittest discover -s Tools/MacBridge -p 'test_*.py' -v
swift test
```

Python 테스트는 임시 프로젝트와 루프백 HTTPS만 사용하며 실제 프로젝트 공유·개인 파일 조회·클라우드 호출은 하지 않습니다.
아이폰 인증서 검증과 LAN 권한은 별도 실기기 검증이 필요합니다.

## 향후 확장

DTO·전송·저장소·화면은 분리되어 있습니다. REA는 선택적 분석 어댑터로만 추가합니다.
현재 토큰에 쓰기·실행 권한을 붙이지 마세요. 생성·수정·검증·실행은 별도의 권한·작업 공간·승인·복구·테스트를 갖춘 새 intent로 구현해야 합니다.
