# JARVIS 기본 명령·대화 200선

이 목록은 현재 JARVIS의 명령 라우터와 Apple 온디바이스 AI를 점검하기 위한 초기 평가 데이터입니다. 같은 뜻을 여러 방식으로 말해도 올바른 기능으로 연결되는지 실제 iPhone에서 확인합니다.

- YouTube, 앱 실행, 전화, 브리핑은 앱의 확정적 명령 라우터가 처리합니다.
- 일반 대화, 작성, 요약, 개인화 요청은 Apple 온디바이스 AI가 처리합니다.
- 서드파티 앱 실행은 단축어 앱에 `앱이름 열기` 동작이 연결되어 있어야 합니다.
- 연락처 이름 전화는 연락처 권한과 실제 저장된 연락처가 필요합니다.
- 아래 문구는 모델 가중치를 직접 학습하는 원본이 아니라 회귀 테스트와 향후 미세조정 데이터의 씨앗입니다.

## 후속 명령 메모리 확인

아래 예시는 각각 두 문장을 순서대로 입력해 직전 명령의 맥락이 유지되는지 확인합니다.

- “오늘 날씨 알려줘” → “그럼 최저는?”
- “오늘 일정 알려줘” → “그럼 다음은?”
- “현재 브리핑” → “남은 일정은?”
- “유튜브에서 아이유 밤편지 틀어줘” → “다시 틀어줘”
- “카카오톡 열어줘” → “다시 열어줘”
- “운동 재생목록 틀어줘” → “다시 틀어줘”

“틀어줘”처럼 대상이 없는 불완전한 음성 명령은 다시 말해 달라는 안내 후 즉시 재청취합니다. 텍스트 입력은 자동으로 마이크를 켜지 않습니다.
