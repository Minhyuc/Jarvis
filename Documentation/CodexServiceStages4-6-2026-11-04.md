# Codex 서비스 1~3단계 재검증 및 4~6단계

## 구현

4단계: App Server의 공식 ChatGPT 브라우저 로그인, 취소, 3분 만료, 완료 확인, 전용 계정 로그아웃을 연결 설정에 추가했다. 비밀번호·토큰을 JARVIS로 입력하거나 인증 파일을 복사하지 않는다. CLI의 기존 로그인은 그대로 유지한다. 로그인 성공은 일치하는 완료 알림 뒤 account/read로 재검증한다. 브라우저를 열었다는 사실을 로그인 완료로 표시하지 않는다.

5단계: 서비스 시작 시 선택적으로 같은 빌드·backend에서 10분 동안 최대 두 번의 전송 계층 자동 복구를 승인한다. 벽시계와 단조 시계를 함께 검사하며 승인 정보를 저장하거나 갱신하지 않는다. 질문은 재전송하지 않는다. 중지·안전 잠금·연결 방식 변경·공간 이탈로 복구 승인을 철회한다. 앱 복귀 시 로그인 상태만 확인하고, 앱/helper 코드 해시 또는 Codex 실행 파일 변경 시 이전 세션을 재사용하지 않는다. 실행 파일 업데이트 후에는 명시적 상태 확인이 필요하다. 연결 방식·복구 옵션만 재시작 후 복원하며 대화와 Codex 로그인은 지우지 않는다.

6단계: 연결 진단 버튼, 고정 helper/Python 버전·요청 수·최근 전체 응답 지연 표시, 서명·프로토콜·인증 주소·시간 초과·실행 파일 변경 안내를 추가했다. 진단에 계정·대화·경로·토큰은 포함하지 않는다. 긴 로그인 대기를 고려해 세션 중복 방지 기록 상한을 128개에서 1024개로 늘리고 상한 도달 시 재연결을 요구한다. 이미 쓴 ID를 조용히 비우지 않는다.

## 1~3단계 재검증

내장 XPC와 Python 어댑터 리소스, 본체 sandbox, 정확한 양방향 서명 조건, 메모리/파이프 페어링, EOF 종료, 수동 CLI 병행을 유지했다. Swift 클라이언트의 실패 콜백 이후 늦은 stop이 새 연결을 중지할 수 있던 순서를 수정했다. 시작 실패를 먼저 정리한 뒤 콜백하며 timeout 콜백의 추가 stop을 제거했다. 앱 안전 잠금은 연결·인증·시작·복구 대기까지 취소한다.

## 검증

Swift 테스트 290개, Python 테스트 50개를 통과했다. 아래는 별도 통합 검증 범위다.

- Swift: 기존 회귀와 신규 로그인 URL·안전 정책·복구 만료/범위/횟수 테스트.
- Python: 로그인 완료 재검증, 취소·만료·잘못된 주소, 고정 HTTP 인증 경로, 계정 없는 logout 확인, 업데이트 시 RPC 종료와 무재전송.
- UI 합성 검증: 승인 없는 서비스 시작 불가, 자동 복구 최대 두 번, 중지·빌드 변경으로 대기 취소, 재시작 시 표시 설정만 복원, 낡은 로그인 승인 차단, 기존 대화 저장/삭제 승인/입력 동작.
- 실제 sandbox 임시 앱: 코드 identity 확인, 인증 없는 요청 거부, 기존 소유자를 침범하는 두 번째 연결 거부, 네 번의 시작·종료·재시작, 포트 종료, 시작 중 취소.
- 실제 설치된 Codex: 임시 CODEX_HOME에서 OAuth 시작·주소 검증·pending·취소·빈 계정 logout. 기존 개인 로그인은 읽거나 수정하지 않고 브라우저/모델 호출도 하지 않는다.
- Mac ad-hoc 서명 빌드, unsigned iOS Simulator 빌드.

관련 도구: `check_service.py`, `check_auth_protocol.py`, `check_mac_ui.py`, `test_app_server.py`, `CodexServiceLifecycleTests.swift`.

## 사용 방법과 남는 제한

현재 내장 서비스는 한 창이 소유한다. 다른 창에서 연결하려면 기존 창의 연결을 먼저 해제해야 한다. 새 창이 기존 창의 실행 중인 작업을 강제로 끊지 않도록 두 번째 연결을 거부한다.

최신 Mac 앱 → 멀티 에이전트 → 연결 설정 → App Server → 보조 서비스 시작·자동 연결 → 필요한 경우 ChatGPT 로그인. 기존 전용 로그인이 유효하면 재로그인하지 않는다. Python 3·Codex 설치는 여전히 필요하다. 로그인 UI는 전용 App Server에 제공하며 기존 CLI는 원래 로그인 방식을 유지한다.

사용자가 브라우저에서 실제 계정 인증을 완료하는 수동 단계, 실제 Mac 절전/네트워크 전환의 장시간 테스트, 여러 macOS 버전과 Developer ID 배포·공증은 자동 검사만으로 완료를 단정하지 않는다. UI는 인증 완료 알림과 계정 재검증 전까지 성공을 표시하지 않는다. 자동 업데이트 설치·로그인 시 OS 자동 시작·모델 질문 자동 재시도·파일/셸 도구·다중 사용자 서버는 추가하지 않았다.

공식 규격: [OpenAI App Server 인증](https://learn.chatgpt.com/docs/app-server#auth-endpoints). 이 구성은 개인용 로컬 앱 범위다. 상업용·호스팅 서비스로 전환할 때는 Sign in with ChatGPT 방식과 당시 정책을 다시 검토한다.
