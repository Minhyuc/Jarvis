# Codex 프로젝트 작업 5~6단계 검증

## 구현 범위

- 전용 프로필의 프로젝트 세션 저장·확인된 마지막 turn 재개·최신 완료 위치에서 분기.
- 폴더별 세션 목록·요약 페이지 조회, 개별 승인 후 보관/복원·영구 삭제·실제 완료를 기다리는 문맥 압축.
- 작업 중단·저장 실패·루트/프로필/프로토콜 변경은 제한된 로컬 문맥으로 새 세션 구성. 기존 네이티브 기록은 관리 목록에 남기며 승인·실행을 재생하지 않음.
- 미확인 작업은 보관/복원으로도 미확인 표식을 유지. 관리 작업 취소로 응답을 확인하지 못한 경우 성공을 표시하지 않음.
- 호스트 도구 10종. 등록한 MCP 서버/도구의 목록·스키마 확인·호출, 검토한 스킬 문서, 선택적인 Tavily 검색.
- MCP·검색 실행과 결과 공유를 따로 승인. 작업 시작 시 확장 설정 고정. 검색 자격 증명은 Mac Keychain에 저장하며 도구 인자에 포함하지 않음.

## 검증 방법

- `swift test --scratch-path /tmp/jarvis-stage56-swift-build --jobs 4`: 331개 통과. 도구 스키마·자격 증명 차단·기존 저장 형식 호환·확장 설정/이력 변경의 승인 및 긴급 잠금 포함.
- `python3 -m unittest discover -s Tools/CodexLocal -p 'test_*.py'`: 112개 통과. 재시작 후 재개, 최신 turn 확인, 프로필 변경, 취소·늦은 관리 응답, 손상 메타데이터 보존, 문맥 압축 완료 확인, 보관/복원 후 불확실성 보존 검사 포함.
- `JARVIS_UI_BUILD_PATH=/tmp/jarvis-stage56-ui-build python3 Tools/CodexLocal/check_mac_ui.py`: 실제 임시 소스 파일 변경/백업, 합성 검증 결과, MCP/스킬/검색의 개별 승인과 결과 공유, 알 수 없는 확장/비활성 검색 거절, 완료 turn의 원자적 저장·분기 참조·참조 해제 검사. 실제 계정이나 검색 키를 사용하지 않음.
- Mac Debug와 unsigned iOS Simulator 빌드 확인. 기존 테스트 파일의 iCloud 다운로드 지연으로 전체 테스트를 임시 빌드 경로에서 재실행함.
- 설치된 `codex-cli 0.169.0-alpha.11.1`에서 생성 스키마 검사와 비로그인 임시 프로필의 experimental initialize, 10개 dynamic tools를 포함한 thread/start 확인. 모델 turn은 시작하지 않음.

## 남은 실제 서비스 검증과 제한

OAuth 인증을 마친 실제 MCP 서버 호출, Tavily 키를 사용하는 실제 검색, 실제 계정 모델이 새 도구를 선택하는 전체 흐름은 별도의 실사용 확인이 필요하다. 합성 테스트와 실제 서비스 완료를 혼동하지 않는다.

스킬은 검토한 문서 참고 기능이며 임의 스크립트를 실행하지 않는다. 플러그인은 기존 관리 창에서 MCP 정의를 검토해 연결하는 범위이다. 공식 앱의 계정 전체 대화/설정 동기화, 임의 셸·내장 권한 실행, 컴퓨터 제어는 포함하지 않는다. 세션 기록은 전용 로컬 프로필에 남을 수 있으며 메타데이터 해제는 원본 영구 삭제와 다르다.

새 보조 프로그램 빌드는 `2026.11.18.1`, 호스트 도구 프로토콜은 `agentVersion=2`다. 기존 연결 서비스는 재시작하고 최신 Mac 앱을 실행해야 한다.
